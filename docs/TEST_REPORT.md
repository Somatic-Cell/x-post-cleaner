## テストで確認した主な条件

日時の半開区間，JST/UTC変換，DST重複の拒否，IDの精度保持，
不正なモデル確率の拒否，confidence と削除候補確率の区別を確認しました．

アーカイブのJSラッパー除去，ZIPを展開しない読込，分割ファイル，重複排除と競合検知，
本文を切り捨てない取込，原子的ロールバック，所有者混在の拒否を確認しました．

分類・翻訳のキャッシュ，ルール変更時のprofile分離，文字数超過時のローカル保留，
翻訳に失敗しても原文へフォールバックしないこと，失敗結果を分類済みとしないことを確認しました．

HTTPのモックで Jev / Azure / X の要求と応答の形式，OAuth 1.0a 署名ヘッダーの生成，
モデル版のずれ，確率の異常，HTTP拒否，レート制限，DELETEのタイムアウト，
不正な成功応答と自動再送をしないことを確認しました．

削除サービスでは，本人/投稿者/本文の照合，手動承認，注意フラグ，人間の選択の尊重，
件数上限，送信前の状態保存，成功/失敗/結果不明，中断からの回復と明示的な再確認を確認しました．

各テストにはソケット接続を禁止するfixtureを適用しています．
HTTPは httpx.MockTransport，削除サービスはFakeXを使用しています．
ユーザーの投稿・アカウント・APIキーは使用していません．
