# 削除とプライバシーの取扱い

このソフトウェアのテストを通ったことは，判定が正しいことや，
X・Jev・翻訳サービスの規約適合性を保証しません．実データを送信する前に，
契約・データ処理条件・利用料金を確認してください．
健康状態の推定ではなく，本人が指定した公開方針への文面の適合を扱います．

## 実削除の条件

既定で削除を有効にしません．有効化には `run --mode review` または `auto` と，
`--enable-delete --ack-irreversible --expected-user-id <数値ID>` が必要です．
設定だけで本人の確認を省略する mode は `auto` に限定しています．

削除用のアカウントIDは DB のアーカイブ所有者ID，`GET /2/users/me` のIDと一致する必要があります．
さらに削除前に `GET /2/tweets/{id}` を行い，その投稿のID・所有者・本文を照合します．
別人の投稿，本文の変化，再投稿，編集履歴付き投稿は拒否します．
判定結果も現在の revision のDB保存結果と一致しなければ使いません．

`auto` は追加で，Jev の分類が DELETE_CANDIDATE，そのクラスの確率が指定閾値以上，
アーカイブと現在の投稿の双方に文脈注意フラグがない，人間の選択が一切保存されていない，
という条件を要求します．`NEEDS_CONTEXT` やデモ用の値を根拠に自動削除しません．
`--auto-threshold 0.98` のような値は，誤削除率2%以下を意味しません．

`--max-deletions` はこの起動で送信する DELETE 要求の上限です．既定20件で，失敗も数えます．
実行をやり直せば別の起動なので上限を新たに数えます．恒久的な課金予算ではありません．

## エラーが起きたとき

削除成功は，成功HTTP応答の `data.deleted` がブール値 true で，曖昧な付加エラーがないと
確認できた場合だけです．タイムアウト，通信切断，不正な成功応答，5xxや中断は unknown です．
4xx の明確な拒否は failed とします．404を「削除済みだったから成功」とみなすことはありません．

1件がエラーになれば，auto は停止します．review はその投稿に留まり，エラーを表示します．
どちらも自動で削除を再送しません．再起動しても該当投稿は通常の候補キューから除外します．

```bash
# 外部通信なし。本文ではなく未解決のID・状態・エラーコードを見る。
post-review status --db .local/review.sqlite3 --details

# 現在の存在と本文を照合するだけ。DELETEは送信しない。
post-review --env-file .env reconcile --db .local/review.sqlite3 --post-id POST_ID --expected-user-id YOUR_NUMERIC_USER_ID

# 同じ投稿が存在すると確認できた場合だけ，手動での再確認へ戻す。
post-review --env-file .env reconcile --db .local/review.sqlite3 --post-id POST_ID --expected-user-id YOUR_NUMERIC_USER_ID --reset-if-present
```

再確認に戻した後も承認の記録は残るため，auto で勝手に再送しません．
実削除を有効にした review，または `--include-approved` で人間が再確認します．
照合時の404/403は存在を確認できなかったということであり，未知の結果を成功へ書き換えません．
その状態を手動で「消えているが操作の成否は断定できない」と整理する専用UIは初版にありません．
確認済み deleted を未要求へ戻す機能もありません．

## 端末とDB

通常の確認画面に表示した原文や英訳は，Textual の画面内で差し替えます．
一方，元アーカイブと SQLite にデータが残ります．このDBは暗号化されていません．
ローカルの権限，暗号化ストレージ，バックアップ先の扱いは利用者が管理してください．
端末録画・シェルのセッション記録・画面収録を無効にする機能はありません．

原文中のANSI制御文字や方向制御の一部を表示用にエスケープし，
Rich/Textual のマークアップとして解釈させません．判定する原文は書き換えません．
通常の例外出力は安全なコードのみです．デバッガ，開発用の詳細ログ，
Textual の開発ツールなどを外部に共有する場合は，別途内容の確認が必要です．

`.env` をコマンド引数に値として渡さず，ファイルまたは環境変数で設定します．
`.env` はリポジトリ直下の指定ファイルだけを読み，親ディレクトリを自動探索しません．
HTTP のTLS検証は無効にせず，API キー付きのリクエストでリダイレクトを自動追跡しません．
プロキシ環境変数の自動継承も無効です．企業ネットワークなどのプロキシ対応は今後の検討事項です．

## 残るリスク

分類モデルは誤ります．高いスコアでも，冗談，引用，過去形，強い比喩，
会話の文脈を誤読する可能性があります．prompt injection に対する数学的保証もありません．
実データのラベルを作り，特に「残すべき投稿を削除候補とする率」を検証してください．

X の事前照会と削除は一つの原子的操作ではありません．両者の間に状態が変わる可能性を
完全に消してはいません．サーバー側の条件付きDELETEは利用していません．
DBを破壊・改ざんできるローカル攻撃者に対する安全性も保証しません．

このツールはローカル原本のバックアップを自動作成しません．
削除後の返信関係や反応を含めて元の投稿を復元する機能はありません．
実削除より前に，自分が保管するアーカイブを確保してください．
